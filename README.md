# ADZ-tech Digital Solutions

Site vitrine Next.js 14, TypeScript, Tailwind 3.

## Développement
npm install
npm run dev

## Déploiement
Pousser sur GitHub : Vercel compile automatiquement.

## Variables (optionnelles, valeurs par défaut dans lib/site.ts)
NEXT_PUBLIC_SITE_URL, NEXT_PUBLIC_CONTACT_EMAIL, NEXT_PUBLIC_CONTACT_PHONE,
NEXT_PUBLIC_WHATSAPP_NUMBER, NEXT_PUBLIC_FACEBOOK_URL
